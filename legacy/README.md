# Archivo histórico del sistema legacy

Este directorio contiene material preservado del ERP que continúa funcionando
en Lovable Cloud. No forma parte del baseline ejecutable de CALAMINA ERP v2.

## Reglas

- No aplicar estas migraciones a una base v2.
- No desplegar estas Edge Functions como funciones v2.
- No usar los archivos Drizzle como autoridad de esquema.
- No reutilizar URLs, project refs, claves o secretos mencionados aquí.
- No modificar el contenido archivado salvo para corregir documentación
  inequívocamente histórica.

El contenido se mantiene exclusivamente para análisis, trazabilidad y diseño de
la futura migración de datos.
